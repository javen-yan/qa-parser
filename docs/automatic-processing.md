# 无人工介入的自动处理验证

日期：2026-11-07。当前版本 0.2.0，macOS ARM64 / Python 3.13.3。这里的自动处理指流程自行结束并交付结果，不表示任何输入都能百分之百成功。

## 已执行的更新计划

1. 可靠 LaTeX 优先。先验证 OMML 高频失败和 MTEF 条件横线堆叠，只做有明确源结构、测试与边界的薄适配。
2. 仍失败时，严格绑定同一 OLE 对象的预览图，保留原字节、ShapeID、关系及哈希。使用 Pillow/libwmf 转换，不能只改扩展名。
3. 不能可靠保留的公式自动隔离所在题目；答案缺失、选项不完整、串题、导出限制等结构问题仍独立阻断。不会因有图片而放行。
4. `run` 一次交付成功 Excel/图片、隔离清单与完整任务证据，不等待用户逐题修改。完全无可用题时仅交付报告，不能生成空 Excel 冒充成功。
5. 运行单元回归、九份真实样本、独立 Excel/资源检查和重复运行比较；不开展 Windows 或 UI 工作。

## 公式与图片的真实统计

实际导出的 7 个公式图片出现于 5 道题。其余成功转换或成功兜底的公式可能位于仍含其他错误的隔离题中，不能计为交付成功。所有图片均引用到真实文件并核对哈希，导出共 906 个图片文件（含普通插图和7个公式图片）。

OMML 597 个对象全部通过本轮有限结构转换；MathType 2244 个对象中2068个文本转换成功，余176个尝试原图。最终40个原图转换通过，136个因字体/编码未验证隔离；另10个普通Word跨对象上下标没有可靠预览，因此共146个公式节点无法保留。

WMF的136个失败按首个命中原因：Symbol字体98、宋体18、未验证字符集161共16、Batang字体3、MT Extra字体1。不能用会漏掉中文、Ω或箭头的PNG代替原图。无预览的未知OMML不走猜测的OMML→LaTeX→PNG路径；MathJax等也不能直接证明未知OMML的忠实渲染。

## 自动产物与运行

最终汇总：`outputs/auto-final/summary.json`。每份文档目录下包含：

- `summary.json`：整个任务与真正导出部分的独立计数，及导入/渲染未验证状态。
- `quarantine.json`：隔离题号、原因、源位置与公式ID。
- `task/`：源DOCX快照、原始公式/预览、解析结构、资源及校验报告。
- `export/`：`questions.xlsx`、`images/` 与记录遗漏/公式结果的 `report.json`。
- `repeat/`：本次自动回归的第二次运行证据，日常单次 `run` 不产生此目录。

```sh
.venv/bin/qa-parser run reference/MathType公式化学填空2.docx --kind blank --out outputs/new-auto-run
```

路径必须不存在。命令无需人工确认；0为全量导出，2为自动结束但存在隔离，1为执行失败并给出错误。开发调试仍保留parse/validate/export；默认配置 `formula_fallback=image`，可用isolate关闭兜底进行对照。

代表性样例：

- `outputs/auto-final/MathType公式化学填空2/export/questions.xlsx`：80道题，第65题原文 H₂SiO₃ 公式使用 `images/0041.png`，题干原位置为“请参考 0041.png”；第35题答案斜分式使用 `images/0029.png`。
- `outputs/auto-final/MathType公式化学3/export/questions.xlsx`：93道题，第49题解析中的 R 公式分别使用0060、0061、0062三个图片引用，保留各次出现的位置。
- `outputs/auto-final/微软公式化学/export/questions.xlsx`：100道全部导出，包含条件公式的有限LaTeX适配，无图片兜底。

已实际打开检查 H₂SiO₃、斜分式和R的PNG，结合原对象绑定与上下文核对；没有用生成式图像或另一个文档的内容填补输入。

## 验证与限制

- **99 项测试通过**：包含正确原图关联、错误ShapeID不得借图、纯色/空白/损坏图、假扩展名、WMF静默缺字风险、缺工具、结构错误不放行、全部隔离、异常输入证据、超长Excel单元格逐题隔离等。
- 九份样本均完成重复运行，任务语义及资源一致。
- 独立读取XLSX ZIP/XML核对列、字段、行数与隔离映射；公式图片原预览哈希、输出PNG哈希、尺寸、引擎和出现顺序均检查。
- 核心Python wheel构建通过；这是开发包，不是客户免安装应用。
- 现有69道隔离题由流程自动排除并列明原因，不要求客户逐题操作；它们并没有被成功转换。
- 结构转换接受不等于全部公式视觉逐项验收；保留输入中的横线上下方向等差异，不擅自纠错化学表达。
- 目标系统Excel导入、图片上传/关联、所有LaTeX命令支持、Windows和客户便携打包仍未验证。

本机的libwmf0.2.13是可选外部转换工具，字体及再分发许可需要在后续客户分发阶段处理。当前没有Windows环境不阻塞此Mac闭环。

下一步如继续提高覆盖率，应优先验证Symbol/中文等预览字体的成熟渲染组件或明确的源公式子集，仍以自动隔离作为无法保证保真时的最终路径，不转回人工逐题修正UI。
