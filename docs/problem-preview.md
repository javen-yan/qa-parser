# 未导出题目的只读预览与原因说明

本次新增解释能力，不改变自动转换、公式图片兜底、题目隔离与 Excel 模板规则。九份样本
仍为 900 题，其中 831 题导出、69 题未导出。客户不需要人工截图、重新排题或逐题修复。

## 69 题的实际原因

源对象审计逐项核对了 146 个问题对象及 136 张对应原始 WMF 预览，源位置与文件 SHA
均与原 DOCX 一致。69 题分为两组：

- 63 题：MathType 公式的结构或字符尚未适配，原预览图又未通过字体/字符编码保真检查。
- 6 题：Word 将下标单独保存，当前转换器无法可靠确定它附属于哪个表达式；10 个下标
  原文已确认是八个“2”和两个“3”，没有独立公式原图。

本批没有文档损坏、答案缺失、选项错位或图片缺失记录。136 个 MathType 原预览的首个
阻止条件为 Symbol 98 个、未核验字体名 18 个、字符集 161 共 16 个、Batang 3 个、
MT Extra 1 个。这是对象数，不是题数，也不代表原图只有这一种风险。没有证据断定
具体哪一个符号会丢失，因此界面不会猜写缺失符号。

完整分组、全部原题号、每个对象的源位置与代表题见 [源对象审计](isolation-audit.md)
和 `outputs/problem-preview-audit.json`。

## 客户操作

转换完成后，从文件行点击“未导出题目”，按原题号查看。窗口保留源文件名、题型、
可读取的题干、选项、答案和解析；高亮标记对应具体问题，点击标记可跳到原因与影响。
诊断码、原始错误及 XML 源位置默认折叠。

- 可靠文字、图片及支持的公式在原字段位置显示。
- 无法可靠转换的公式显示占位；分离下标只保留已证实的原文字，不猜测它的归属。
- 不用已拒绝的 WMF 转换图冒充原文。原图不能安全预览时提供“打开源 Word”入口，
  通过系统默认程序打开已验证的源快照。查看 Word 需要系统有相应查看程序，转换本身不需要 Office。
- 预览是字段内容与问题定位，不是 Word 整页重建，也不表示该题已成功导出。
- 文档无法读取时明确说明不能确认题目内容/数量；没有问题的文件明确显示没有未导出题目。

默认与最小 760×600 窗口均能使用，题号导航与题目内容独立滚动。界面没有编辑、批准
或要求客户修复的步骤。

## 最终交付包

每份有未导出题目的文档增加一个 `未导出题目.html`，只包含该文件的未导出题目及其
必要预览资源。HTML 自包含图片、公式脚本和字体，可离线打开，题号和问题标记可跳转。
Excel 仍只包含通过检查的题目；成功题不重复进入问题预览。

TXT 说明也记录每道题的具体字段、原因和影响。原 Word、OLE/WMF 对象、中间任务、诊断
JSON 和日志不进入客户 ZIP。只有已验证且确实用于预览的安全图片会嵌入 HTML。
全失败批次不生成空成功 ZIP；若仍能读取问题题目，则在失败说明旁保留单独编号目录中的
只读 HTML。

## 离线公式与安全边界

使用随应用携带的 KaTeX 0.19.1、WOFF2 字体和 MIT 许可，不在运行时下载资源。只有原转换
状态可靠的公式进入渲染器；失败公式不会借预览机会重新猜测转换。

九份样本的隔离题上下文共有 684 处可转换 LaTeX，严格预览模式能显示 561 处，另 123 处
（主要是中文数学文本等）明确提示“公式显示暂不支持”并保留可展开源码。这是预览渲染
限制，不是新增隔离题，也不会改变 Excel 内容。详见 `katex-render-check.json`。

源文字用 DOM 文本或 HTML 转义显示；原图须通过路径、SHA、格式和像素检查，再编码为 PNG。
拒绝 SVG、任意本地路径、外部图像命令及不可信 HTML 命令。HTML 使用脚本哈希 CSP，禁用
网络连接、表单与外部资源，字体和图片仅用 data URI；有图片大小及累计内嵌预算。
