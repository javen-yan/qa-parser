# Mac 本地转换界面

## 使用

在当前项目目录双击 `启动题库转换.command`，会通过 Terminal 打开默认浏览器中的本地转换页面。Terminal 窗口在运行期间保持打开，转换结束后点击页面的「退出工具」，再关闭窗口。此脚本是当前 Mac 项目的启动入口，需要与项目和现有 `.venv` 放在一起；不是可复制到任意电脑的独立分发包。

1. 选择「自动识别」，或明确选择「选择题」「填空 / 考点」。
2. 添加一份或多份 `.docx` Word，也可拖入文件。
3. 默认保存到用户「文稿/题库转换结果」，可点击「更改位置」，在页面内浏览个人文件夹并选择保存位置。
4. 点击「开始转换」。每个文件分别展示进度和最终状态。
5. 点击「打开结果」取得 Excel、图片；「查看说明」在页面内显示未导出题号及原因。

部分失败表示结果不完整，已通过题目仍保留。失败文件不影响其他文档。新建转换只清空当前文件列表，不删除已经生成的结果。每批、每份文件均有独立输出目录，同名 Word 不会覆盖。

关闭浏览器页面不会中止正在进行的转换。刷新同一个页面可以继续查看当前任务。完成后点击「退出工具」关闭本地服务。当前界面不恢复进程被强制终止前的列表；已经保存的源文件、任务及导出结果仍留在结果目录。

开发调试入口：

```sh
.venv/bin/python -m qa_parser ui
# 显式指定开发验证输出位置
.venv/bin/python -m qa_parser ui --out outputs/界面转换结果 --data-dir outputs/ui-session
# 同一批量核心的命令行入口
.venv/bin/python -m qa_parser batch reference/*.docx --mode auto --out outputs/new-batch
```

## 技术决定及依赖

界面采用本地 HTML/CSS/JavaScript，宿主采用 Python 标准库；复用现有转换内核，没有引入 UI 框架、Node 运行时、远程脚本、在线字体或新的转换组件。默认浏览器承担页面渲染；现阶段无需 Rust/Tauri 重写。此方案优先验证客户操作闭环，未来独立运行时打包仍须单独处理。

Python 运行时使用 [PSF 许可](https://docs.python.org/3/license.html)，现有转换组件的许可及原生依赖见 `THIRD_PARTY_NOTICES.md`。此次 UI 没有新增第三方运行依赖。浏览器自动化工具仅用于开发检查，不是应用依赖。

[Python 官方文档](https://docs.python.org/3/library/http.server.html) 明确说明 `http.server` 不适合生产 Web 服务。本项目把它限制在本机开发/预览工具：只绑定 `127.0.0.1`，校验 Host、Origin 和随机会话令牌，静态资源采用固定白名单，不能作为外网网站部署。文件上传限制每份 128 MB、每批 100 份。上传目录、日志位于用户数据目录；结果写入用户所选位置，程序不会向自身安装目录写入任务数据（开发者明确指定项目输出目录除外）。

系统差异只放在 `desktop.py`：当前实现 Mac 打开目录；文件夹浏览使用本地页面与 Python 文件系统接口，仅支持当前用户个人文件夹内的位置。Windows 没有执行验证，本轮不添加 Windows 适配、CI 或发布包。

## 正文题型判断

`classification.py` 保存规则版本及逐题证据；文件名不参与判断。

- 完整且有序的 A/B/C/D 选项是选择题证据，答案合法性继续由内核校验。
- 填空标记、明确填空指令及独立答案构成填空题证据；填空大题内部的选择小问保留在大题内。
- 只见普通编号小问或「回答下列」等指令不足以断言填空题。
- 同一文档出现不同大题类型，或任一题的证据不足，整份文档明确失败，不猜测模板。
- 指定题型模式同样检查正文，发现不匹配时不导出。

这套规则针对现有样本结构，不承诺任意 Word 自动识别。公式的可靠文本转换、绑定原图兜底、结构及资源检查沿用已有内核，不降低导出门槛。

## 验证与边界

见 `docs/mac-ui-validation.md`。真实系统导入、图片上传关联、APP 公式显示、Windows 和独立便携分发仍未验收。当前「成功」仅表示全部题目通过程序转换检查。

本机曾尝试 `.app` 启动探针，但 LaunchServices 启动的 Python 被 macOS 文件访问权限拒绝读取文稿目录里的虚拟环境。未修改系统权限，改用已实际验证的 Terminal 双击脚本；探针保留在 `outputs/launcher-probe/`，不作为交付入口。
