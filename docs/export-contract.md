# Excel 导出约定与验证边界

新版 `run` 会自动调用校验与部分导出，交付成功包和 `quarantine.json`，无需人工确认。下文的显式 `allow_partial` 是底层导出API的兼容边界；公式原图兜底不会解除题目结构错误。当前自动验证记录见 `automatic-processing.md`。

导出层使用小型第三方库 **XlsxWriter**（BSD-2-Clause，纯 Python），不调用 Office、不启动外部转换进程。通用 XLSX 序列化由库承担，业务字段映射、资源校验及部分导出规则由本项目负责。运行依赖应随未来发行包携带，不要求客户自行安装 Python。

官方资料：

- [write_string 与字符串长度限制](https://xlsxwriter.readthedocs.io/worksheet.html#worksheet-write-string)
- [许可证与再分发要求](https://xlsxwriter.readthedocs.io/license.html)

## 输入与输出

`export_task(task, task_dir, out_dir, allow_partial=False)` 接收 schema_version=1 或 2 的任务，产出新目录：

```
questions.xlsx
images/001.png
report.json
```

任务的 `kind` 为 `choice`、`blank` 或 `mixed`。v2 每题独立保存 `kind` 和组织结构，v1 仍按保存的文档类型读取，不修改旧任务。题目 `issues` 非空即待复核或按明确策略跳过；导出器不会自行消除解析问题。未显式开启部分导出时，只要存在未解决题就拒绝导出。部分导出报告包括完整遗漏题号、问题列表和 Excel 行号与源题号对应关系。没有可通过题时拒绝生成空模板。

混合文档保留一个同名 Excel，在“选择”和“考点”工作表分别使用原有模板列，不新增业务列。报告同时记录工作表、行号、父子 ID、来源位置及材料引用，离线预览读取全部工作表。此布局是供复核的暂定导出方案，目标系统是否接受多工作表仍未验证，不能宣称可直接导入。

## 复合结构与填空回填（候选实现）

组织结构（独立题、共享材料题组、带子问、连续编号空）与作答方式（单选、填空、未支持）独立识别。共用材料题组的每个可独立作答子题一行，继承材料及图片；答案与解析按明确题号绑定，不按位置猜测。连续编号空仍属于同一道题，不按空位编号拆为顶层题。未知题局部隔离，不以整份文档类型不统一为由拒绝所有正常题。

填空题 `stem` 保留原空位，`knowledge_point` 由业务层按已验证绑定回填成完整陈述，导出层不重建语义。多个空位的答案用 ASCII `,` 连接；一个空位内的中文逗号、斜线同义词原样保留。原答案、空位位置、绑定证据及必要的公式内小问标题提取证据保存到任务中，原公式源码及 LaTeX 不改写。无法一一绑定、仅图片内作答、混入无空位开放问答的题目进入复核，不能补解答案。

表格按排版、静态材料、作答交互分别判定。仅真实表内交互填空按策略跳过，保留原文和具体单元格证据；静态数据表、化学过程表和选项布局不因此跳过。元数据不充分则复核。同一圈号明确重复出现时保存别名关系，避免重复计空。

报告分别列原题/题组数、题组展开子题数、输出单元数、导出数、策略跳过数、失败或待复核数。题组展开子题是输出单元的子集，不与原题数直接相加；答案块数不作为分母。输入重复正文单列覆盖统计，不自动删除用户输入文件。

选择题默认列：ID、类型、困难程度、题目、选择项、答案、解析、sid、optionA、optionB、optionC、optionD、title、questionType。填空默认列：ID、考点、题目、答案。

`ID/sid/questionType` 暂空；`title` 同题干，`optionA～D` 同对应选项；`选择项` 按 A．内容逐行保存。`field_defaults` 按列名提供空值默认值；`column_fields` 将列名显式映射到题目字段；`required_columns` 验证已知的必填列。`choice_columns/blank_columns` 允许配置列顺序。真实系统导入契约尚未验证，不能把这些暂定约定称为实际系统支持。

所有单元格使用 `write_string` 写入。以等号开头的内容、LaTeX、数字外观的标识和 URL 均保持文本，不生成计算公式或链接。单元格超过 32767 字符（同时保守检查 UTF-16 单元数）即失败，不静默截断。

## 图片与发布完整性

默认图片引用严格使用`参考aaa001.png)`，aaa 固定为小写，序号至少三位补零（超过 999 不截断），结尾为 ASCII 右括号，不加左括号、“请”或空格；对应实际文件名为`001.png`，保存在本份文档的`images/001.png`。题干、选项、答案和解析共用`image_reference: "参考aaa{filename})"`配置，离线预览按同一模板匹配相对图片。已有任务中的旧模板及显式自定义模板继续按其配置处理，不自动改写旧任务正文；批量导出中每份文档保留独立图片目录。

优先使用每题 `asset_filenames` 清单，同时识别题目导出文本中对任务资源文件名的引用。只复制通过题目引用的资源；检查资源位于任务目录内、扩展名一致、SHA-256 正确。保持原始字节，不转码。未支持的格式由解析/校验层产生待复核问题。

导出先在同父目录临时目录完成校验和写入，再以独占方式创建目标目录，发布文件。目标已存在时拒绝覆盖；正常异常会清理本次临时及未完成输出。`report.json` 是完成标识；应用崩溃或断电留下的无报告目录不能认定为完整包，也不会被后续运行覆盖。

本层测试检查底层 XLSX XML、字面文本、模板列顺序、多小问内容、部分导出、遗漏报告、缺失/篡改图片、目录逃逸、单元格超长及已有结果保护。此测试不能替代目标系统导入或 Office/Windows 运行验收。

## 统一客户交付布局（2026-11-08）

桌面 UI（单份或批量）、`batch` CLI 和 `run` CLI 的最终 ZIP 统一使用原 Word 基名，不再保留数字/非数字两套布局：

```text
1.xlsx
1/001.png
01.xlsx
01/001.png
物理 练习.xlsx
物理 练习/001.png
_说明/0001/结果说明.txt
_说明/0001/题目预览.html
_说明/0001/未导出题目.html  # 仅有未导出题时
_display/                 # 共享离线预览字体及许可证
批次结果说明.txt
```

前导零、中文和空格原样保留，不按上传顺序改名。无图片也保留同名空目录。图片引用仍为 `参考aaa001.png)`，不添加目录前缀或新的导入语法。每份 Word 的说明映射写在批次说明中；辅助内容不放入同名图片文件夹，也不复制旧版 Excel/images 目录树。

UI 开始转换前、批量开始前、单文件 CLI 开始前及打包时均校验交付名称。重复基名、大小写/Unicode 规范等价名称、文件与目录路径冲突、保留辅助目录名、Windows 禁用名称/字符均明确拒绝，提示重命名，不覆盖、不自动附加流水号。内部诊断目录及底层 `parse`/`export` 结构继续使用 `questions.xlsx`、`images/`；它们不是客户最终包。

## 客户更新：文本优先与显示映射

通过源结构转换的公式优先保留原 LaTeX 并使用 `$$...$$` 分隔；不因同一字段多个下标、分式嵌套或上下标组合强制转图。源文档示意图保留原始字节。未知结构、标记污染或不完整语法只使用已绑定的原始预览兜底，没有可靠预览则复核，不能猜测公式。

`report.json` 的 `image_reference_map` 显式记录 `参考aaa001.png)` → `001.png`。aaa 和末尾右括号仅属于显示引用，不能用于拼接文件路径；导出、缺图校验和预览共用这一映射。旧任务继续按已保存的模板和文件名读取。

难度输出为易／中／难，对应旧低／中／高。哈希算法、种子和档位顺序不变；旧任务与人工指定难度在导出时仅映射词汇，不重新随机。

客户截图中的图片全宽放大可能涉及 APP 布局；本次减少不必要的公式图，不改变原始图片含义，也不将本地预览通过视作客户 APP 验收。
