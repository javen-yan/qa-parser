# 题型逻辑走查与点睛删除验收

本轮基于共享图片修复继续检查题目边界、分类、材料归属、答案回填、表格策略和
实际 Excel 导出。状态为本地源码修复完成，尚未构建或发布新的客户安装包。

## 已复现并处理的问题

| 范围 | 原问题 | 当前行为 |
| --- | --- | --- |
| 编号填空 | 答案编号换序或编号错误时退回按位置填入，可能把编号本身写进答案 | 完整且唯一的编号按编号绑定；缺失、重复或不匹配时复核 |
| 圈号填空 | Unicode 圈号被 `isdigit()` 当作普通数字，绕过圈号匹配 | 分开识别 ASCII 数字与圈号；保留仅以圈号作为答案值的合法情况 |
| 数值答案 | `1.5` 可能被视作第 1 空的答案标记而截成 `5` | 小数点不作为题号分隔符 |
| 编号小问 | 多个含空位的小问使用同一编号时，可能共用一个答案段 | 显式答案编号存在歧义时复核；无空位说明段或完整的无编号顺序答案不误拦截 |
| 共享材料 | 材料后逐题给答案、没有可靠题组范围时，前题与后题仍可能显示成功 | 标记前题及可能受影响的范围为材料归属待复核；不按邻近位置猜配 |
| 集中解析 | 无法匹配的编号“分析”可能作为公共分析复制给全部子题 | 编号不匹配时报告解析归属问题；无编号公共分析仍可保留 |
| 题型分节 | 分段处理或共享题组绕过判断题、简答题等标题 | 分节约束覆盖全部题组与后续题，遇到新标题重置；分节标题不混入前题解析 |
| 多选题 | 多选题恰好只有一个答案字母时可能按单选导出 | 明确的多选／不定项标签或分节进入暂不支持，不冒用单选模板 |
| 表格填空 | 表格里的空括号未走表内交互策略 | 空括号与下划线均检查；公式／图片占位不会被误认为空括号 |
| 点精／点睛 | 内容和附带图片／公式进入导出，编号列表也可能误拆题 | 两种标记的内容均不导出，其专属资源不计入导出引用；原始 Word 与块证据保留 |

点睛删除按明确的 `【点睛】`、`【点精】` 标记划分范围。其后的独立题、材料提示、
题型标题和新的答案／解析段保留。编号列表本身不能证明新题；有独立答案的真实
后续题必须保留，即使它属于暂不支持的简答题。

## 题型支持边界

- 单选：仍要求完整选项结构和可对应的单个答案；不求解或猜补答案。
- 填空：保留题干空位，按明确编号或可验证的答案字段布局回填考点；标点、
  同义答案和公式内部空格不充当猜测性的分隔符。
- 共享材料：已识别的集中编号答案按子题分配；逐题给答案而范围不明的情况
  本轮只增加拦截，不声称已经支持自动继承材料。
- 表格：静态材料、选项排版继续保留；表内交互填空按现有策略跳过。
- 混合卷：仍逐题分类，选择与填空分别使用现有工作表；判断、简答、作文、多选
  等不支持的作答方式明确复核。
- 图片和公式：继续保留来源与资源校验；图片中的隐含空位、没有明确结构提示的
  材料范围、非标准答案标记不属于本轮新增支持。测试不能证明任意 Word 排版均可识别。

## 4.docx：同标点解析步骤误拆

源文档实际101题。旧解析将第83题分析中同样使用全角点号的三条连续操作步骤误拆为题号1、2、3，形成104个候选；三个伪题与真正的1、2、3冲突，导致6条未导出。

修复限定为：处于分析／详解／解析段，前文明确引出步骤、方法等并以冒号结束，后续有从1开始的连续编号列表，列表项无独立答案。完整新题或缺少该上下文的重复编号仍按原规则识别、复核。普通题及共享材料题组使用同一边界证据。

实际导出101/101，0未导出。原正常98题中只有第83题补回缺失解析；其难度占位值随完整原文内容哈希重算，不代表教学难度重新评估。其余97题字段不变。原reference的1,920题逐题对照无变化（1,822导出、98策略跳过）。

问题预览同时明确“原题号”是Word题干前编号；同号题显示原文第几处、题干开头和结构位置，并在重复原因中列出同号内容，避免只见两个相同的“第1题”。不凭重复提示认定源文档有错。

本地证据：`output/doc4-verified/verification.json`、`output/doc4-public-tests.json`。交付文件：`output/doc4-verified/最终结果/题库最终结果.zip`。本轮改动尚未进入已发布的v0.3.5安装包。

## 题目边界整体复查（含4.docx）

本轮检查普通题、共享材料题、编号解析、步骤列表、不同编号分隔符、独立简答、缺答案题、点睛／点精、重复编号及空位小问。补充发现并修复三类合成反例，以及一处真实文档中的解析串题：

1. 普通新题变换编号标点（例如全角点改为顿号），即使有独立答案也可能被并入前题。现在独立答案优先于分隔符惯例。
2. 共享材料题组后接不同分隔符的完整简答题，可能被吸收进题组解析。现在按独立答案识别新题，不限于选择／填空。
3. “操作步骤：”后的编号项如果包含选项或文字空位但没有答案，可能被当作普通说明放行。现在这类作答结构阻止合并，缺答案题保留并复核；解析中的“A、B、C错误”等引用不冒充选项组。

4. 4.docx第97、98题的“公共分析＋编号解析”原先被整段复制给两题。现在公共部分两题保留，编号部分分别归属；重复或无法唯一匹配的编号继续复核，明确的公共操作步骤不拆成子题解析。

补充连续编号列表的27种分隔符、分析段标记、引导语组合验证，以及真正重复题、无答案题的负例。缺少明确引导语、编号不连续或归属不清的内容仍按原规则保留复核，不以“看起来像步骤”为由强行合并。

最终19份Word共2,021个输出单元：1,923题导出、98题原表格策略跳过、0待复核。相对第83题修复后的基线，2,019题逐项不变；仅4.docx第97、98题的解析归属得到修正，其难度占位值随内容哈希变化。所有题号、类型、题干、答案、选项、考点、解析状态及问题状态不变。扫描226处保留在题干／解析中的编号段落时，发现并修复了上述97、98题问题。

500项公开回归通过、79项按既有策略排除，无意外跳过。证据：`output/boundary-audit-final/verification.json`、`output/boundary-audit-final/public-tests.json`。4.docx更新后的交付文件为`output/doc4-boundary-final/最终结果/题库最终结果.zip`，101题全部导出。这是当前样本及合成边界覆盖结论，不保证任意新文档均无歧义；本轮修复尚未打包发布。
