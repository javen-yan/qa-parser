# 特殊题型解析与导出

缺少解析不会使题目失败：输出 `analysis_status=absent`、`analysis=解析无`。
普通填空继续按明确的空位与答案对应关系回填考点，选择、填空原有 Excel 表头不变。

## 实际处理规则

`special_questions.enrich_special_question` 在普通结构绑定之后、公式和资源校验之前处理：

- 独立简答或图示作答：题干、唯一答案完整，没有选择选项、文字空位或归属异常。
- 图内填空：题干确有图片，没有文字空位，保留原始图片和答案，不猜测图内坐标。
- 填空与简答混合：题干、答案的小问编号必须唯一且顺序完全对应；每个小问必须有答案；所有文字空位仍须通过普通填空绑定检查。

上述题以 `response` 类型正常导出到“特殊题型”工作表，列为 ID、原题号、类型、题目、答案、解析。
保留完整原题、原答案，缺解析显示“解析无”，不生成虚构的已填考点。
`special_response` 保存原类型、已解决的问题、规则版本及不推断答案的声明。

明确标注的不支持题型、答案归属不明、缺失或重复小问、空位数量不匹配、资源或公式异常仍须复核。
表格策略跳过保持原判定。显式编号答案为空时拦截，避免开放小问被普通填空路径漏掉。
特殊题和普通题共用资源哈希、公式、Excel 长度及导出预检，不通过修改校验状态来绕过检查。

## 公式修复

- Word 明确括号组内的空格，以及外层上下标末尾的空格，不再拆断相邻化学式。保留源片段与定位；闭括号和上下标之间有空白、括号不匹配等情况仍不绑定。
- 已识别字体、匹配 Unicode 字符及显式粗体属性的 `+ - =` 转为保留粗体的 LaTeX。未知字体、粗体字母及其他自定义样式继续拦截，不放宽 WMF 字体检查。
- MathType 对齐值 `(1,129,129)` 仅支持经第 62 题原始树与 WPS 截图核对的单列两行条件结构：第一行双下划线条件、第二行空白、无分隔线。保留两条横线、条件、空白行，不猜生成等号或箭头；其他未知矩阵继续拦截。

## 未解决题目的交付

只有仍未解决的问题进入 `特殊题型待后处理.zip`，保留原始 Word、字段、相关图片、公式源数据和预览。
包位于最终交付的 `_说明/对应序号/`；资源按哈希校验并原子生成。
全局文档错误仍按文档隔离；后处理包失败不会撤销已经通过的普通导出。
