# Mac 本地界面与批量验证

本记录区分批量核心、浏览器交互与最终客户交付。自动检查通过不表示全部公式已经人工核对，也不表示真实系统导入、Windows 或客户便携包已经验收。

## 可重复执行

在项目开发环境运行：

```sh
.venv/bin/python scripts/check_batch.py --out outputs/ui-validation
```

输出位置必须不存在。脚本只读取 `reference/`，生成的任务、导出包、合成异常样本和验证记录均放在指定输出位置；默认对照 `outputs/customer-flow-validation` 的 Mac 基线。其他基线可用 `--baseline` 指定。

批量核心检查覆盖：

- 自动识别全部九份 Word，逐文档核对题型和 100 道题数。
- 九份输出的全部 Excel 字符串、图片文件名及 SHA256、未导出题号与原因，逐项对照既有 831 导出 / 69 隔离基线。
- 指定选择题、指定填空题各转换一份真实 Word，核对与基线一致。
- 两份同名、中文及空格路径的 Word 使用不同题目和图片，中间插入损坏 Word；验证两个正常文件分别成功、图片从各自包内独立编号、损坏文件不影响后续。
- 混合题型和无法确定类型的正文不猜测导出；手动选择与正文明显不一致时失败；把填空内容命名为“选择题.docx”仍识别为填空。
- 批量进度单调更新，每文件都有最终状态和可读报告，不遗留“处理中”。
