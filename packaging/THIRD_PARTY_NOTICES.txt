The application uses Python, pywebview, PyObjC, lxml, olefile, omml2latex,
XlsxWriter, Pillow, bottle, proxy_tools and typing_extensions. Original license
texts supplied by their distributions are retained in this directory; the
build manifest records versions. PyInstaller's bootloader has an exception
permitting bundled applications to retain their own license, subject to the
licenses of dependencies. It does not override any dependency's conditions.

The isolated wmf2gd helper and libwmf libraries are from libwmf 0.2.13 (GPL /
LGPL / GD components). Their exact upstream source archive, Homebrew build
recipe and macOS patch are included under libwmf/sources. This package modifies
Mach-O dynamic-library references for relocation and applies local ad-hoc code
signatures; source algorithm code is unchanged. These files remain replaceable
in wmf/bin. Original copyrights, source and licenses are preserved. The
Nimbus / URW font license and original font sources are included as part of
the libwmf source archive. Font files themselves are unmodified; fontmap paths
are rewritten at runtime into a writable temporary directory.
